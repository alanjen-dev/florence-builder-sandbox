# Builder Allowed Scope

This sandbox builder is allowed to handle only small, reviewable cleanup work.

Allowed:

- Add or update documentation files.
- Add small fixture files for reviewer tests.
- Make narrow text-only cleanup changes.
- Use GitHub pull requests as the review surface.

Not allowed:

- Secrets, credentials, or token material.
- Production repository changes.
- Runtime, daemon, service, or LaunchAgent changes.
- Vault, Personal Zone, Mac mini, DGX, or OpenClaw changes.
- Broad refactors or multi-area edits.
